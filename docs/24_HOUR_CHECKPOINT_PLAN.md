# Resumable 24-hour work plan — not a runtime promise

The request is larger than a universal catalogue can honestly deliver in one day. This checkpoint implements acquisition evidence, 32,226 accepted metadata entities, offline/static and SQLite discovery, unknowns/rights gates, durable resume and measured synthetic scale. Execution is finite; no subscription-independent bot, 24-hour daemon or scheduled routine has been created.

Suggested **effort windows**, resumable by another developer/AI:

1. Hours 0–2: reproduce checks, verify pinned input hashes, compare accepted coverage and quarantine, inspect rights and native examples. Current checkpoint does this; preserve git history and datasets.
2. Hours 2–5: resolve the one missing-title source item from a genuine cited revision; review source anomalies, writers versus singers, work/recording overlaps and language aliases. No guessed credits/metadata.
3. Hours 5–9: define permissioned label/independent-artist feed contracts, editorial/takedown policy and evidence retention. Build a source backlog for underrepresented languages/artists, not popularity-only inclusion.
4. Hours 9–13: obtain appropriately budgeted official core mirror/dump access for album/release/performer chronology. Do not blindly download 23 GB or crawl a free-noncommercial API for an ad business. Add source adapters with dry-run, identity, resumability and rights tests.
5. Hours 13–17: benchmark realistic overlapping/native queries, incremental updates, concurrent reads, backup/restore and memory/network budgets. Use synthetic fixtures only in isolated databases, never to inflate real counts.
6. Hours 17–21: native editorial/accessibility/device review, improve source-profile aliases, filters and precise chronology when facts exist. Validate static-host asset quotas and optional API operations; keep curated reading ad-free.
7. Hours 21–24: verify actual free deployment origin/headers/404s, useful original content and operator policies; configure Search Console only with owner verification, actual publisher ID/CMP only after approval; rerun CI and publish a reviewed PR/checkpoint.

At every stop: commit code/docs/tests, retain immutable source manifest, `coverage` report, quarantine hashes, import run IDs/byte offsets and source fetch journals. `npm run catalogue:bootstrap` resumes local work without refetching a source. Another environment can clone the PR, bootstrap the shipped CC0 snapshot, build and continue. No promise of all Indian songs, #1 ranking, instant indexing, ad approval, earnings or zero bugs.
